プライバシーポリシー

tanaka-stream（以下「このアプリ」）は、運営者自身の YouTube チャンネルでライブ配信を行うための、個人用のアプリです。使うのは運営者本人だけです。

扱う情報

このアプリは、Google の許可画面で運営者本人が許可した範囲で、YouTube Data API を通じて次の情報を扱います。

  • 運営者のチャンネルの名前と ID
  • 運営者のチャンネルのライブ配信と動画の情報（タイトル・説明・サムネイル・配信の状態・視聴の数など）
  • ライブ配信のチャットに書かれたコメント（配信の中で読むため）

使いみち

ライブ配信の枠を作る・始める・終える、タイトルやサムネイルを設定する、動画を載せる、配信の中でコメントに答える、ためだけに使います。

保存と共有

  • 情報と、Google から受け取った認可のトークンは、運営者のパソコンの中にだけ保存します。
  • 第三者に売ったり、渡したり、広告に使ったりしません。
  • 運営者以外の人の Google アカウントの情報は集めません。

許可の取り消し

許可は、Google アカウントの「サードパーティのアプリとサービス」のページ（https://myaccount.google.com/connections）からいつでも取り消せます。取り消すと、このアプリは YouTube の情報を扱えなくなります。

YouTube の決まり

このアプリは YouTube API サービスを使っています。YouTube の利用規約（https://www.youtube.com/t/terms）と、Google のプライバシーポリシー（https://policies.google.com/privacy）もあわせてご覧ください。
